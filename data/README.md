# Dataset

Download the original IBM Telco Customer Churn CSV from:
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

Extract and place `WA_Fn-UseC_-Telco-Customer-Churn.csv` in `data/raw/`.

The original CSV is kept unchanged and excluded from Git. It contains 7,043 customer records and 21 columns. `Churn` is the binary target and `customerID` is an identifier.

IBM describes the telecommunications company as fictional:
https://community.ibm.com/community/user/blogs/steven-macko/2019/07/11/telco-customer-churn-1113
