## Overview
This project investigates customer churn using the IBM Telco Customer Churn dataset. It covers exploratory data analysis (EDA), data cleaning, and builds two binary classification models—**Logistic Regression** and **Random Forest**—to identify customers at risk of leaving.

## Project Structure
- `notebooks/`: Contains `telco_customer_churn.ipynb` with complete data cleaning, EDA, preprocessing pipelines, and model evaluation.
- `report/`: Contains the final PDF report (`Customer_Churn_Report.pdf`) and working notes.
- `figures/`: Visualizations generated by the notebook (churn distribution, contract rates, boxplots, ROC curves).
- `data/raw/`: The dataset (`WA_Fn-UseC_-Telco-Customer-Churn.csv`).
- `requirements.txt`: Python package dependencies.

## Dataset
- **Source**: [Kaggle - Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) (IBM sample data representing a fictional telecom company).
- **Size**: 7,043 raw records (7,032 after cleaning, removing 11 zero-tenure rows with blank total charges).
- **Target**: `Churn` (after cleaning: 73.42% stayed, 26.58% churned).

## Key Results
Models were evaluated on a stratified 80/20 train/test split (5,625 train / 1,407 test):

| Model | Accuracy | Precision | Recall | F1-Score | ROC-AUC |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Logistic Regression** | **80.45%** | **64.95%** | **57.49%** | **0.6099** | **0.8359** |
| **Random Forest** | 78.61% | 62.46% | 48.93% | 0.5487 | 0.8128 |

Logistic Regression achieved higher ROC-AUC and detected more churners at the default 0.5 decision threshold on this test split.

## How to Run
All setup commands should be run from the **project root**:

1. Create a virtual environment using **Python 3.13.9**:
   ```bash
   python3 -m venv .venv
   ```

2. Activate the virtual environment:
   - **macOS / Linux**:
     ```bash
     source .venv/bin/activate
     ```
   - **Windows (PowerShell)**:
     ```powershell
     .venv\Scripts\Activate.ps1
     ```

3. Install required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Open `notebooks/telco_customer_churn.ipynb`, select `.venv` as the notebook kernel, and click **Run All**.
