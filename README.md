# Telco Customer Churn

COMP-551DL Business Intelligence assignment exploring customer churn using the IBM Telco Customer Churn sample dataset.

Status: project setup. Analysis and modeling have not started.

## Project structure

- `notebooks/`: analysis notebook and model evaluation.
- `data/raw/`: original dataset stored locally; see `data/README.md`.
- `figures/`: exported analysis and evaluation figures.
- `report/`: assignment report.
- `reference/`: local assignment brief and downloaded archive (excluded from Git).

## Dataset

Source: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

The dataset represents a fictional telecommunications company. It is IBM sample data, not actual IBM customer records.
